Organizador de tareas

Gestiona tus entregas con opciones claras para agregar, quitar y planificar tus próximas asignaciones.

Opciones disponibles

  • Agregar tarea: Crea una nueva tarea con fecha de entrega y prioridad.
  • Quitar tarea: Elimina tareas completadas o que ya no necesitas.
  • Calendario: Revisa las fechas de entrega y organiza tu semana.
  • Futuras asignaciones: Guarda lo que viene para no olvidarlo.

Ejemplo de uso

  1. Abre Tareas para agregar o quitar tareas.
  2. Marca las fechas importantes en tu calendario.
  3. Revisa Calificaciones para ver si necesitas priorizar alguna asignatura.
  4. Usa Contacto si quieres pedir ayuda o consejo.
