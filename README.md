# La Esquinita

La Esquinita es un mini proyecto para la organización de tareas universitarias. El objetivo es ofrecer una experiencia simple, visual y accesible que permita a los estudiantes controlar entregas, filtrar tareas por curso, buscar de forma instantánea y guardar su lista de pendientes en el navegador.

## Funcionalidades

- Diseño de interfaz para organizar tareas universitarias
- Filtro por curso y estado
- Búsqueda instantánea en la lista
- Marcar tareas como completadas
- Agregar y eliminar tareas propias

## Archivos principales

- `index.html`: página de bienvenida y descripción del proyecto
- `tareas.html`: página principal del sistema de tareas
- `eventos.html`: página de organizador con opciones generales
- `calificaciones.html`: página de resumen de notas
- `contacto.html`: página de contacto
- `acerca.html`: página con información del proyecto
- `styles.css`: estilos globales

## Cómo usar

Abre el archivo `index.html` en el navegador o usa un servidor local simple para ver el sitio en funcionamiento. La página de tareas (`tareas.html`) es donde se encuentra la aplicación interactiva.
